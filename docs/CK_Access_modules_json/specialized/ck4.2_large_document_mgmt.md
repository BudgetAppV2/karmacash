# CK4.2: Large Document Management (Optimized)

## Large Document Handling for CG Handoffs
When handoffs involve large documents or extensive content, CK must structure for CG success.

## Document Size Considerations
- **Single Session Limit**: CG must complete within conversation constraints
- **Content Chunking**: Break large documents into manageable sections
- **Progressive Delivery**: Structure handoffs for incremental completion
- **Quality Maintenance**: Ensure comprehensive coverage despite size constraints

## Quality Management
- **Consistency**: Maintain uniform style and structure
- **Completeness**: Ensure all essential information included
- **Accessibility**: Structure for easy navigation and reference
- **Maintainability**: Design for future updates and extensions
## CG Implementation Guidelines
- Focus on core content first
- Use established templates and patterns
- Maintain quality over quantity
- Document any incomplete sections for future work
