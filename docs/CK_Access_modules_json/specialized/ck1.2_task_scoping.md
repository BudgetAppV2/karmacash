# CK1.2: Task Scoping (Optimized)

## Single-Session Constraint
All tasks must be scoped for completion within one conversation session.

## CK Scoping Framework
### For Technical Implementation Tasks
1. **Define Success Criteria**: What constitutes completion for CG?
2. **Identify Blockers**: What could prevent CG completion?
3. **Resource Assessment**: What tools/data does CG need?
4. **Complexity Estimation**: Can CG implement well in one session?
5. **Integration Requirements**: How does this fit existing system?

### For Strategic Planning Tasks
1. **Outcome Definition**: What decision/direction needed?
2. **Information Requirements**: What data is essential vs nice-to-have?
3. **Implementation Readiness**: What detail level does CG require?
4. **Handoff Completeness**: Does handoff contain all necessary context?

## Handoff Quality Gates
### Pre-Creation Validation
- Measurable completion criteria
- Production-ready deliverables or clearly marked drafts
- Comprehensive documentation and handoff materials
- Clear next steps and dependencies
- CG has all tools and information needed

### Implementation Scope Validation
- **Single-Session Feasible**: CG can complete within conversation limits
- **Tool-Complete**: All required MCP tools available to CG
- **Context-Complete**: All necessary project context included
- **Dependency-Clear**: Prerequisites identified and addressed
- **Quality-Defined**: Success criteria and validation steps clear

## CK Handoff Scoping Process
1. **Requirements Analysis**: Extract specific deliverables from TaskMaster
2. **Context Gathering**: Collect technical context, integration points, dependencies
3. **Scope Definition**: Define exact deliverables and success criteria
4. **Handoff Creation**: Create comprehensive handoff with all context

## Anti-Patterns to Avoid
- ❌ Vague, open-ended objectives without specific deliverables
- ❌ Tasks requiring multiple sessions to complete
- ❌ Deliverables that cannot be validated or tested
- ❌ Missing prerequisite information or dependencies
- ❌ Scope expansion during handoff creation
